廠務工具 V5.5.4

通用版 · FY圖示 · 四項簡易工具與完整工程工作台

本版處理數字鍵盤輸入、單位說明與照明體積欄位，加入即時空氣線圖及七系統設備表匯入。既有分段空調箱與完整工程工作台保留。

項目新版行為
數字鍵盤小數點／地區小數分隔鍵統一輸入ASCII「.」；支援取代選取文字，不影響普通Delete。套用於主要與子視窗的輸入欄。
溫度差更名為「溫度差（升溫／降溫）」。5°C差＝5K＝9°F差；若換算某個溫度，選「溫度」。
Kv／Cv更名為「閥門流量係數（Kv／Cv）」，說明水流量／壓差定義與型錄用途；Kv≈0.865Cv(US)。
空氣狀態即時畫出目前乾球／含濕比點位、RH曲線、焓與壓力。改值先清除舊點位，驗證通過後重畫。
照明體積格明列m³，淨高格明列m；90m³÷3m＝照明面積30m²。切換m²／坪／長寬／體積保持面積。
設備表Excel一檔七系統，CSV一檔一系統；按供應群組分開彙總，另列全開與同時需求。

一鍵安裝

  1. 解壓縮Facility_Studio_V5_5_4_OneClick.zip。
  2. 雙擊Facility_Studio_V5_5_4_Setup.exe，首次保持連網。
  3. 等候建立應用EXE與桌面FY圖示捷徑，再開「Facility Studio V5.5」，確認顯示5.5.4。
目標Windows 10/11 Intel/AMD x64。這是線上安裝器，會下載官方Python及套件並在本機建立應用EXE。已編譯Windows PE安裝器、核對CRC、完整解壓及57個內含檔案。本次實際測試環境為Linux／Tk；Windows實機安裝與實體數字鍵盤尚未完成驗收。安裝器未具商業程式碼簽章。

設備範本怎麼填

  1. 開啟懶人包內的Facility_Studio_V5_5_4_Equipment_Template.xlsx；也可在軟體右上「設備表匯入」→「1 匯出Excel範本」。
  2. 保留工作表名稱及第5列欄名，在黃色欄填實際設備數據。要納入的列把啟用設1；範例啟用0。
  3. 功率、流量與插座數填每台數據，設備台數另填。各系統可用相同設備編號對應，同一系統內不可重複。
  4. 按「2 匯入設備表」，上表看需求與尺寸候選，點選一列看條件、公式與設備明細。匯出TXT／JSON保留全部資料。

選填參數空白會帶入預設並列出採用值；必填空白、無限數、重複編號與錯誤單位會指出系統／列號／欄位。輸入欄公式需貼上值；灰色公式欄不作為工程計算依據。預留100列，更多設備請在下方欄位提示之前插入列，最多每系統10,000筆。

系統彙總及定寸方式重要條件
電力各盤／相數／電壓分組，列kW、P/Q/S、電流、NFB與線徑候選、單台支路與插座數。插座不再乘功率；不同供電不直接合併電流。支路按額定；進線不低於已納入最大單台支路需求。進線壓降採設計電流與阻抗上界。
PCW水量×台數×同時率，各列ΔT分別計熱量再加總，列主管流量及參考管徑。清水ρ=1000、cp=4.1868；未核泵揚程及換熱器。
CDA／N2標準流量統一至25°C／101.325kPa(abs)，再換管內實際量定寸。採已填最低絕壓、最高溫度、最低流速上限；不同壓力級次仍須核減壓及供應架構。
EXHAUSTGEX／SEX／AEX／VEX／HEX分開，列方管與圓管。設備端靜壓只列最大已知要求；未知保留空白，不相加為風機總ESP。
DI製程同時水量＋全部額外持續循環量，列最小實際內徑。持續循環量不乘同時率；水質與實供材質另核。
PV標準／實際量、絕壓換算、管徑初估、製程端有效抽速。Torr(abs)／kPa(abs)／mbar(abs)，限1~760Torr；未核導通、洩漏、放氣及泵曲線。

同時使用率是瞬間需求估算係數，不能當成每小時運轉比例。安全排氣、吹掃及常時需求須另核。正式盤體尺寸、短路遮斷、相別分配、接地、完整管網與原廠選型仍需要現場／原廠資料。
