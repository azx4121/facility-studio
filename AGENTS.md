# AI collaboration rules

- Protect existing worktrees, fixtures, evidence, releases, and credentials. Run tests that write evidence in an isolated checkout.
- Keep macOS and Windows source differences. Preserve licenses, notices and attribution.
- Only one agent edits a given engine file at a time; exchange task specifications, commits, diffs and test evidence rather than assuming shared chat context.
- Never change engineering formulas or default assumptions without explicit scope, units, input conditions, independent reference, negative tests and regression review.
- Do not merge, publish releases, expose secrets, or connect paid APIs without the owner's approval.
- Treat source tests, native binary acceptance and real-machine UI tests as distinct evidence. Record host, source platform, commit, command and result.
