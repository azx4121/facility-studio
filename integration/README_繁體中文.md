# Facility Studio 5.7.2 測試版

本版新增兩項功能：

- 主畫面「設計依據與交付審查」：新增獨立專案，填寫設計工況、驗收準則與適用規範，逐項附加設計文件。規範每行採「名稱｜版次｜條號｜適用範圍｜來源」。人工覆核者須與編製者不同；變更設計依據／交付清單或修改證據後，舊覆核不再有效。儲存及匯出均建立新檔，不覆寫前版。附件是附加當時的快照；來源文件更新時須重新附加，不能沿用舊版代表新版。移機時請複製整個設計審查資料夾，包括 evidence 子資料夾。
- 「液體／純水管路」頁可勾選「加做泵浦吸入校核」。填入液槽表面絕壓、最低液面相對泵高度與吸入側總壓損；本頁的主路徑壓損不會自動當成吸入損失。純液體蒸氣壓依溫度計算，混合液須另提供泡點壓力與同工況來源。依工況原廠 NPSHr 及專案額外裕度比較；缺資料、吸入口閃蒸或裕度不足時不判為符合。變更流量／物性／管徑後，須重新填妥吸入壓損及泵曲線依據。

「文件齊備，可送工程審查」只表示所填文件與人工覆核紀錄齊備，不驗證簽章身分或代替工程師審查。多區壓差網、完整管網、保護協調、施工圖與現場驗收仍須另外完成。

本版使用獨立名稱與資料目錄，不替換原本的 App 或專案。介面預設繁體中文。

1. Mac 解壓後開啟「Facility Studio 5.7.2 測試版.app」。Windows 使用新的空目錄安裝，或完整解壓 Portable 資料夾後開啟 EXE。
2. 左側「PV 真空快算」可直接輸入標準氣體流量與絕對壓力，不切換完整工作台。標準量與管內實際量不同；換單位會保持原物理量。
3. 左側「液體／純水管路」選介質、材料與流量。提供管徑、內徑、流速、壓損、物性及保溫結果。從冷熱水頁按「液體與管材選擇」可帶入流量；不會替你更換介質、材料或物性來源。化學液體或混合廢液缺少可靠工況資料時會要求密度、比熱、動力黏度與來源，不沿用水的數值。
4. 改變介質、濃度或操作溫壓時，供應商物性來源需重新確認；高流速、過高壓損或不成立的管壁尺寸會在原頁提醒或阻擋。
5. 帶入冷熱水流量後，上游變更會使液體結果失效並阻擋匯出；先重算上游，再明確重新帶入。按「查看設計參考資料」可開啟來源，完整網址仍留在報告。
6. 「單位換算」是唯一的換算入口。AHU 模型差異核對用於同條件數值偏差分析，不是另一份設備負荷設計。
7. 潔淨室新案預設 ACH 表示 FFU 總送風；MAU 外氣已包含其中。明選回風另加外氣的舊案保留該基準。報告明列額外所需洩壓／排放量，未設排放路徑不能保證室壓。
8. 風管結果另列參考鐵皮厚度與番號。目前引用內政部106年研究的中壓矩形參考；仍須依實際壓力、補強、接縫、材料及契約規範選用。
9. 保溫同時使用管外徑、液體溫度、環境溫濕度、導熱係數、外表面熱傳、允許熱損及契約最小厚度。顯示厚度 t 與外表面溫度；外徑未知時需補實測或產品資料，不能把內徑當外徑。
10. 主工作台「進階工程設定」保留盤管與冬季、水路物性及設備用電連動條件。單機 AHU 可用幾何盤管性能計算核對冷量、乾球與含濕比是否同時可達。

本次為獨立候選版；正式發布須完成工程資料、既有回歸與跨平台成品驗收。詳細測試證據及接續審查清單另附於開發交接資料，不混入工程計算報告。
