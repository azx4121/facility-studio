# Facility Studio 5.7.0 五庫融合測試版

本版是獨立安裝、獨立資料的工程計算軟體測試版。主程式、報告及預設介面均為繁體中文，不需付費 API、常駐服務或另裝 Python。

## 五套工具實際使用的位置

| 工具 | 直接接入產品的流程 | 原邏輯取捨 |
|---|---|---|
| PsychroLib | 主案、單機 AHU 與空氣工具的飽和壓、焓、比容 | 保留輸入範圍、超飽和攔截、乾空氣零含濕量及專案分子量比基準 |
| python-hvac | 主案與 AHU 盤管熱質平衡；單機 C2 實體幾何 ε-NTU 能力與兩側壓降 | 保留 ADP/BF 需求反算；幾何模型另核冷量、乾球與含濕比可達性，不把需求點冒充實際出風 |
| fluids | 主案水路／風管、冷熱水與其他 Darcy 快算的 Colebrook 摩擦因子 | 保留過渡區插值及警告、專案實際內徑表與自訂管徑；新增水速＋摩擦壓損聯合選管 |
| CoolProp | 主案各水迴路與冷熱水快算，可按明填溫壓取得純水物性；AHU 獨立物性模型核對 | 保留混合液與廠商自訂物性；使用 HEOS／IAPWS-95，不誤稱 IF97 |
| Pint | 既有單位工具、風量／水量讀取及表單換單位 | 溫度與溫差分開；表壓基準、PF、馬達效率及 Kv/Cv 等工程情境明列 |

python-hvac 的物性使用 CoolProp，不能算第三種獨立物性模型。PsychroLib 已成為產品核心，同庫對照屬一致性檢查；不同模型對照使用 CoolProp，另保留解析式、物理守恆及固定案例測試。

## 操作

1. Mac 解壓後開啟「Facility Studio 五庫融合測試版 5.7.0.app」。可將此獨立名稱 App 拖入應用程式資料夾；不覆蓋原 Facility Studio。Windows 可使用 Setup 或將整個 Portable 資料夾解壓後開啟同名 EXE。
2. 主畫面按「完整工程工作台」→「工程模型設定｜五庫融合」。可直接編輯 BF 下限、盤管端差、冬季 FFU 比例、MAU 送風上限、末端 HW 熱源、壓損警戒及 NP 連動。
3. 純水：主案模型設定選本迴路「CoolProp 純水溫壓」，填實際水溫與絕對壓力。冷熱水快算也有同一選項。乙二醇／混合液保留手動物性，不能冒用純水模型。
4. 選管：選「流速與摩擦壓損」，填本案限制。400 Pa/m 為沿用的專案警戒初值，不是通用法規；若指定小管徑超限，報告會列出未達。
5. 單機 AHU：開啟進階設定，選「幾何 ε-NTU（python-hvac）」並填 C2 尺寸、管排、內外徑、翅片間距、並聯路數與實際水量。幾何初值為合成範例，不能冒充既有設備型錄。
6. 水洗泵：填「水洗泵總輸入電力」及轉入空氣比例。電力計入裝機總量；入熱比例未知時如實顯示待資料，不假設全部入熱。
7. NP：可選自動加總本案。手填值此時代表額外負荷；泵／排氣軸功率依明填馬達效率換電氣輸入，FFU 入室發熱不當成電氣輸入。帳本已有 NP 來源時阻擋重複連動。
8. 冰機：報告分列本案空調同時峰值與水路供冷容量包絡。只有確認各迴路為獨立冷源負荷後，才採用包絡選型；同一主／次側負荷不可重複相加。

預設資料在家目錄「Facility Studio 五庫融合測試資料-5.7.0」。此位置與原版分開。舊專案匯入保留原欄位與假設；請另存到本版測試資料夾，不覆寫原檔。

## 驗證與工程邊界

交付包附來源雜湊、版本、實測命令、退出碼及驗收 JSON。實際測試數以同一交付版本的證據為準。可執行檔支援 `--fusion-self-test 結果.json` 及 `--sandbox-self-test 結果.json`，均使用合成資料。

本版不宣稱取得完整 FEED 設計簽核、Apple 公證或 Windows 商業簽章。工程資料不足、能力未達及待後續階段項目會如實顯示。無依據的「FEED 65%～70%」及通用特氣安全流速數字不作為產品認證；亦不以關閉系統安全功能取得執行資格。

Claude／Gemini 依使用者用量限制暫停，不虛稱已完成三方審查。本輪不合併 main、不公開 Release、不替換既有 App 或 Hub。
