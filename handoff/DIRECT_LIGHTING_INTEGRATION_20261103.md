## 功能與工程界線

- 平均流明法旁新增獨立的「配置／直接照度」視窗。只從明確匯入的 IES／LDT 配光、每盞位置／高度／水平旋轉及工作面網格計算，不把流明法平均值假造成空間分布。
- IES 僅支援 LM-63-1995／2002、Type C、TILT=NONE；LDT 僅支援文件列明的單燈組、Isym 0／1／2／4、均勻 C 平面及零測量傾角。其他或損壞格式拒絕，不猜測修復，也不讀取外部 TILT 檔案。
- 直接光採逆平方距離與接收面餘弦，對原始光強雙線性內插。維護係數只乘一次；不套用流明法利用係數。格心取樣的平均、最小、最大、均勻度及內插等照度線均標示其範圍。
- HTML、逐點 CSV 及 JSON 保留採用配置、來源 SHA-256、解析倍率、初始／維護後照度。輸入或來源變更會失效舊結果，另存對話框期間也重新核對；原子寫入避免中斷時毀損既有報告。
- 這不是 DIALux 等價引擎。反射、日光、遮擋陰影、UGR、傾斜燈具、多工作面、法規符合及完整 FEED 均未實作或未認證。格點極值不代表連續空間極值。此階段尚無結果 JSON 專案重新載入。

## 整合覆核追加

1. 對所有結果補上遠場有效距離必須由原廠確認的限制；全零尺寸的來源另外警告無法確認實體尺寸及有效距離。0.01 m 是數值幾何下限，不是精度保證；已有尺寸也不因超過五倍尺寸就自動取得精度認證。
2. 補上獨立、倍率不互相抵消的 IES／LDT 測試，以及不對稱 LDT 的 Isym 2／4、非均勻 gamma、環繞接縫及錯誤數值測試，避免常數配光掩蓋錯誤鏡射。
3. 補上存檔對話框期間來源替換／移除、增加未使用來源、成功結果替換，以及寫入中斷時保留既有檔案的回歸。
4. 新檢查已加入既有 Linux 來源與 Windows 原生 CI 命令；工作流程權限仍為 contents: read。分支觸發範圍尚須在取得遠端推送許可後核對，沒有宣稱遠端 CI 已跑。
