# FEED 能力差距、待補代碼與驗收證據

這是程式碼與工程交付差距評估，不是「FEED完成百分比」或認證證書。ChatGPT／Claude／Gemini的審查屬軟體與工程邏輯審閱，不能取代業主Design Basis、具資格設計者簽核、實體材料與現場試驗。

| 範圍 | 待補程式碼／資料結構 | 應有驗證與標準適用紀錄 |
|---|---|---|
| 設計依據與規範 | `design_basis.py`：司法、業主、系統用途、標準名稱／版次／條號、來源雜湊、適用範圍、覆核者；資料版本移轉與過期判定 | 用戶／業主核定設計依據及驗收矩陣；版本及引用可追溯，不宣稱通用FEED認證 |
| 材料與化學液體 | `material_catalog.py`、`chemical_properties.py`：產品／樹脂牌號、OD／最小壁厚、壓溫降額、濃度、密封與接合、危害分類／二次圍堵／相容性來源 | 供應商同工況資料、SDS、材證、接合資格、適用ASME B31.3與業主規範；不得由材料名稱或SDS單一數字判全部相容 |
| 液體壓力網路 | `liquid_network.py`：支／幹管節點、靜揚程、最小壓力、閥權度、控制閥／泵曲線、NPSHa／NPSHr、水錘與設計壓力；非牛頓獨立模型 | 與獨立水力工具、解析式、廠商工作點及最不利案例比對；壓力／洩漏試驗、耐蝕與支撐計算依適用規範 |
| 廢液與污水 | `gravity_drainage.py`：重力／滿管選擇、坡度、充滿比、通氣、含固體／沉積、自清流速與非牛頓警示 | 確認排水用途、法規與業主安全要求，不能把滿管Darcy結果當重力污水容量 |
| 高純水 | `upw_quality.py`：材料溶出、表面、焊接／清洗、循環／死角、水質／監測與衛生設計欄位 | 適用SEMI F57等依據、供應商溶出與潔淨資料、現場水質／沖洗驗收；不能僅流速與壓損判高純度合格 |
| 風管構造 | `duct_construction.py`：選材料、正負壓等級、矩形／圓管、接縫／補強／吊架、最小實際板厚、契約表匯入與來源；番號與mm分開儲存 | 合法SMACNA／契約表及適用版次；泄漏、強度、施工與消防要求分開驗。106年政府研究只能參考，不能直接核准施工 |
| 管路保溫 | `insulation_codes.py`：適用能耗最小表、公稱徑／OD、k(T)、防燙、防潮／熱橋、室外風雨日射、材料耐溫及結露容許準則 | 解析圓柱熱阻、獨立保溫工具與廠商條件比對；現場接縫與蒸氣阻隔驗收；ASHRAE舊表不能冒充現行強制規範 |
| 真空 | `vacuum_network.py`：實際氣體／混合氣、黏滯／過渡／分子導通率、可壓縮沿程壓降、管件、泵曲線與氣載交點、外壓失穩 | 各流態解析式／Leybold工具及原廠曲線；氣密、漏率、污染及泵保護要求；超出模型不給有效抽速合格判定 |
| 空調與無塵室 | `pressure_cascade.py`：多區壓差與洩壓／排氣節點、連續性、門與氣閘室；盤管幾何模型／原廠同工況交叉核對 | 熱濕／乾空氣守恆、跨區網路、最不利季節與控制工況；ISO14644潔淨度／現場測試不由ACH代替 |
| 電力及保護 | `short_circuit.py`、`protection_coordination.py`：電源阻抗、故障電流、Icu/Ics、選擇協調、UPS／發電機盤分流、失效後載流 | 用戶用電設備規範與適用電氣標準、廠商TCC／保護資料及現場檢驗；熱量不當用電，重複馬達不加算 |
| FEED交付物 | `pid_export.py`、`io_schedule.py`、`mto_bom.py`、`review_workflow.py`：P&ID／控制理念／I/O／設備規格書／MTO／CAPEX與審查版本 | 業主交付清單、工程師跨專業審查、HAZOP／風險審查（依用途）、需求到測試與文件的追溯 |
| 軟體發布 | schema移轉、失效快照、測試資料來源、跨平台凍結版本、版本化規範庫、SBOM／授權／簽章／雜湊／升版與回復 | Mac／Windows原生與移機離線測試、獨立工程基準、回歸與GUI、發布資產完整性；AI審查紀錄另列，不冒充法規證明 |

上列是本次原始碼稽核推導的待辦架構，檔名為建議新增模組，**不是聲稱已存在或已完成**。每項驗收須寫出適用案例、誤差門檻、失敗處置與負責覆核者。正式標準／業主條件尚未給定時，Claude可完成可配置程式與測試，但不得把空白規範與未知數據變成「認證通過」。官方來源及已查證範圍見 SOURCES.md。
