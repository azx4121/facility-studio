# Facility Studio 5.7.3 護鎖與警告修正

範圍：12 項簡易工具、完整工作台、單機空調箱，以及來源快照、停用欄位、複製／匯出／回傳操作。本版不改工程數值方程或擅自新增法規門檻。

## 已重現並修正

- 特氣相態篩選結果原先未完整進入簡易頁警告、完整工作台及部分可計算的特氣頁。現在已知液化篩選風險列為未達；未確認相態列為待資料。篩選警戒不等同已證明液化，也不代表施工核定。
- 水／液體頁有超速警告卻顯示綠色完成狀態；風管壓力不足被一般參考警告掩蓋。現在畫面、結果卡及報告一致呈現警告，已知未達優先。
- 「待後續」品質狀態原先可呈綠色，完整工作台首則說明亦可能先顯示缺資料而隱藏未達。現在未達為紅色，待資料／待後續為黃色，首則說明按嚴重程度排序。
- 開啟另存視窗後變動條件，可能造成簡易設計總覽匯出舊結果、完整工作台 JSON 匯出空結果，或文字／圖形匯出出錯。所有相關匯出於選好路徑後再次比對結果與輸入快照，變動即停止且不產生檔案。
- 完整工作台複製／匯出成功原先會將狀態改成綠色並蓋過工程警告。現在操作成功仍保留品質狀態及警告。

## 驗證方法

`integration/test_guardrails.py`：78 個實際 Tk 操作測試，含 12 工具各自的 NaN／Infinity／空白、修正恢復、停用欄位保留與重新啟用、壓力不足、超速、已知／未知相態、另存期間變動、錯誤主案與過期快照回傳。另沿用全部工程回歸、材料／保溫／板厚適用條件、單位換算與跨平台欄位稽核。

`facility_studio/guard_acceptance.py`：63 項成品護鎖操作，隨打包軟體執行；加上原有 52 項介面驗收共 115 項。測試使用合成資料，不操作正式 App 或使用者專案。原始失敗、修正後退出碼、各平台結果及成品雜湊分別留存於本輪證據包；數字以交付驗證摘要為準。

- 特氣自訂流速超過內建參考，或氣體沒有內建流速基準時，新增畫面、報告及完整工作台「待資料」提示。採用原有參考數值，沒有將參考表冒充法規安全上限。

- 已知不成立的潔淨室氣流／除濕、FFU 覆蓋率、保溫、泵浦吸入及真空有效抽速，新增結構化未達狀態並優先呈紅色；單純缺原廠 NPSHr 或裕度依據仍為待資料，不混同已證明物理失敗。

## 使用上可見的變化

紅色表示已知未達或無效輸入；黃色表示警告、待資料、待後續確認或過期結果。合法但有警告的計算可匯出供檢討，報告保留警告；無效／已過期的結果禁止當作新結果匯出。判斷不能只看是否算出管徑或冷量。
