# V5.5.9：100 組無塵室測試後的報告與盤管診斷修正

狀態：來源修正、兩平台來源回歸及 Windows／macOS 原生打包與 GUI 已通過，V5.5.9 EXE／DMG 已公開發布。[實際下載、來源 commit、原生流程及 SHA256](2026-10-11-v5.5.9-native.md)。以下來源檢查與原生結果分開記錄。

## 修正內容

- 完整報告 API 現在先檢查必要結果區段、四個氣體列與 UP／NP 電氣列。將 `calculate(..., isolate_utilities=True)` 的部分空調結果交給 `report()` 時，回傳 `ValidationError(code="incomplete_result")`，說明應修正未通過項目再計算；不再出現 `KeyError: '1'`，也不以零值偽造完整報告。零需求仍有有效結果列，可正常輸出。
- C1 旁通混合產生超飽和時，保留原物理拒絕並回傳 `code="supersaturated_air"`。提示含季節、C1、入口乾球／RH、ADP 與出口乾球需求。主案定位 `pre_t`；單機自動模式定位 `c1_t`；單機分季指定模式定位 `summer_c1_t` 或 `winter_c1_t`。中文與英文提示同步。
- 單機 C1 不一致的內部焓若導致非有限或近零分母，也明確拒絕並定位欄位；不任意設旁通因子為零。正常有效計算公式不變。
- 新增每平台 68 項來源回歸及每次原生執行 8 項實際介面檢查；涵蓋完整報告拒絕、主案／單機定位、英文提示、匯出鎖定與修正後恢復。

## 保留原始 100 組案例再測

輸入沿用 V5.5.8 測試的 100 組不同無塵室、夏冬條件及固定種子，不重設輸入以取得通過。原 JSON SHA256：`d3209ae321f2c8ef5c8946de89f0adbec0006f6a48deec130f9c91fa11c0d759`。新版測試器為 `tools/cleanroom100_stress.py`，需指定這份原輸入 JSON；只更新 C1 錯誤欄位的預期，物理條件不變。

100 案中，78 案可完成整案計算、11 案電氣超出既有表範圍而僅保留空調結果、11 案因設計條件不成立而拒絕空調計算。89 份空調結果的工程判定仍為 28 份「未達條件」、61 份「待補資料」；軟體檢查通過不表示這些設計已可直接選用。

原先三個 C1 超飽和案例 CR062／063／064 現在均定位 `pre_t`；原有 ADP 不足、未啟用加熱／加濕、外氣不足與電氣表上限仍拒絕。DCC 空氣側不足、供水不足等未達判定也保留。
