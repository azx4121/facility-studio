Facility Studio beginner tutorial / 新手操作教學

1. Extract the ZIP completely. 完整解壓縮。
2. Open START_HERE.html with your browser. 雙擊 HTML，用瀏覽器閱讀。
3. Copy/rename a practice JSON before opening it in the Full workbench. 先複製改名，再從完整工作台「開啟」JSON。
4. These are synthetic learning inputs, not client or certified equipment data. 合成練習條件；待補資料仍需補。

The tutorial is offline; external GitHub links need internet. No Python installation is required.
教學離線可讀；GitHub 外部連結需網路。一般使用不需 Python。
