# 照明照度計算器：空間 m²／m³、燈具流明、Lux 與盞數

[English](lighting.en.md) · [回到工具指南](README.md) · [下載](../../README.md#下載)

**Average illuminance and fixture-count calculator.** 開啟「照明照度」，選「估算照度」或「反算燈數」，再選面積m²、坪、長×寬或體積m³。體積需要同一空間淨高，才能得到 `照明面積=體積/淨高`；不是要求把體積欄填面積。

燈具光通量用**流明lm**，空間照度用**Lux＝lm/m²**。瓦數不能單獨決定照度；有型錄就選型錄流明，未知可用LED功率初估，但必須保留採用的光效假設。

Windows **win.5 及後續版本（目前 win.8）**：「型錄 U／室指數檢核」保留原本的面積、計算模式與流明來源。若使用 m²、坪或體積，會提示先選長×寬並填入實際尺寸；不再套用隱藏的舊長寬。只有實際尺寸可用時才啟用 K，U 仍須依原廠配光與反射率表確認。[F07 修正與驗收](../2026-10-18-windows-lighting-f07.md)。macOS mac.6 尚未套用此操作修正。

<a id="case-08"></a>
## 案例08：90 m³、高3 m、40 W×10盞

選「體積m³」，體積填90、淨高3。每盞40 W、10盞，採LED初估100 lm/W、照明利用率U=0.6、維護係數M=0.8。

`面積=90/3=30 m²`；`每盞流明=40×100=4000 lm`。
`平均Lux=10×4000×0.6×0.8/30=640 Lux`；照明用電0.4 kW。

<a id="case-09"></a>
## 案例09：30 m²、目標500 Lux

選「反算燈數」，面積30 m²、目標500 Lux、型錄每盞4,000 lm、每盞40 W，U=0.6、M=0.8。

`N=ceil(500×30/(4000×0.6×0.8))=8盞`。向上取整後平均照度512 Lux、功率0.32 kW；7盞只有448 Lux。

U、M及100 lm/W都是案例假設；應依燈具、反射率、安裝高度、清潔及老化條件確認。本工具估平均照度，不提供配光檔模擬、眩光、工作面各點照度或均勻度保證。

案例輸入：[08](../examples/08-lighting.json)、[09](../examples/09-lighting.json)。[來源反算記錄](../evidence/2026-10-18-audit-six/windows-use-cases.json)。

## 照明設計報告（FEED 初估）

「調整預設值／進階條件」可選填專案名稱、空間名稱、燈具廠牌／型號、型錄或配光資料來源，以及設計基準和 U、M 依據。這些是報告識別與來源記錄，不會改變流明法結果，也不表示已匯入或驗證光度檔。

照明工具「匯出本工具結果」預設為 HTML。開啟 HTML 後可按「列印／另存 PDF」，使用 A4 直式報表。仍可選 TXT；跨模組 HTML 總覽也包含照明明細。

報表列出已採用的幾何條件、平均照度、燈具表、完整燈具總流明、總 W、W/m²，以及依實際平均照度計算的 W/m²/100 lx。平均照度為零時，後一項標示不適用。只輸入面積時，不會套用隱藏的長寬或安裝高度。

Emin、Emax、Emin/Eavg、Emin/Emax、地板／天花板／牆面照度、網格、等照度線、反射光及 UGR 尚未計算。報表會明示缺項，不從平均值補造分布圖。這版不是 DIALux 等價模擬，也不做法規符合判定。

要接續逐點照度，需要原廠 IES／LDT、逐盞位置與方向、房間與工作面幾何、計算網格。反射光另需表面反射率與反射計算模型。詳見[第一階段設計紀錄](../2026-11-03-lighting-feed-report.md)。

## 配置／直接照度（第二階段候選）

照明工具另有「配置／直接照度」視窗，可匯入受支援的 IES／LDT，明填逐盞位置與朝向後計算工作面格點、Emin/Eavg、Emin/Emax及內插等照度圖，匯出 HTML／CSV／JSON。**只含直接光，不含反射及 UGR**；與上述流明法報告保持獨立。[操作、支援格式、計算邊界與驗收](../2026-11-03-direct-lighting.md)。
