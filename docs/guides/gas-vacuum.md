# CDA／N2 與 PV 管徑初估：標準流量、實際流量與絕對壓

[回到工具指南](README.md) · [下載](../../README.md#下載)

**Compressed air / nitrogen / process vacuum flow and pipe calculators.** 管徑需要「流量＋壓力＋允許流速」，只有壓力與流速不能決定管徑。「CDA／特氣管徑」快算接受CDA、N2及Ar；其他氣體與PV使用完整工程工作台。快算是理想氣體、指定流速的截面初估，沒有完整可壓縮管路壓降模型。

標準SLPM／SCFM／Sm³/h與管內ALPM不同。預設標準溫度25°C、標準絕壓101.325 kPa，應與設備型錄一致；氣體溫度25°C、大氣壓101.325 kPa均可調整。`P絕對=P表壓+P當地大氣`，`Q實際=Q標準×P標準/P絕對×T管內(K)/T標準(K)`。

<a id="case-05"></a>
## 案例05：CDA 800 SLPM、6 bar(g)、15 m/s

開啟CDA快算，填800 SLPM、6 bar(g)、流速上限15 m/s，保留上述25°C標準基準。

| 結果 | 數值 |
| --- | --- |
| 管內絕對壓力 | 701.325 kPa(abs) |
| 實際流量 | 115.581 ALPM |
| 理論最小內徑 | 12.787 mm |
| 表內候選 | 1/2英吋（15A），參考內徑16.1 mm |
| 實際速度 | 9.462 m/s |

`D內=√(4×ALPM/60000/π/v上限)×1000 mm`。名目15A不是實際內徑；須依實供材質、壁厚與潔淨要求覆核。

<a id="case-06"></a>
## 案例06：N2 100 Sm³/h、600 kPa(g)、12 m/s

將氣體改N2，標準流量100 Sm³/h＝1,666.667 SLPM。600 kPa(g)相當於6 bar(g)；實際流量240.794 ALPM，最小內徑20.635 mm。參考候選3/4英吋（20A），內徑21.4 mm，實際速度11.158 m/s。

<a id="case-07"></a>
## 案例07：PV 2,000 SLPM、150 Torr(abs)

開啟「完整工程工作台 → 特氣／PV」，填標準抽氣量2,000 SLPM、150 Torr(abs)，進階流速18 m/s、標準及管內溫度25°C、Z比值1。

150 Torr(abs)＝19.9984 kPa(abs)＝199.984 mbar(abs)。`Q實際=2000×760/150=10,133.333 ALPM`；理論最小內徑109.300 mm。本參考表選6英吋（150A）、內徑160.3 mm，實速8.368 m/s。參考表的4英吋內徑108.3 mm小於需求，不能因接近就宣稱符合。

此為**製程真空體積流量初估**，不是高真空、導通率、抽空時間或幫浦性能選型。需另外取得泵曲線、管路導通率、漏氣／放氣量及外壓屈曲資料；Torr／kPa／mbar切換不會把絕壓變成表壓。完整工作台的本路壓力與遠端最低壓力須符合供氣上下限。
