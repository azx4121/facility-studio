# AHU／MAU 分段計算：預熱、預冷、水洗加濕、再冷與再熱

[English](ahu.en.md) · [回到工具指南](README.md) · [下載](../../README.md#下載)

**Seasonal AHU stage requirements and installed-capacity comparison.** 「完整工程工作台 → 單台空調箱」可設定冬夏工況，各段採自動需求、旁通或指定出口乾球；冷卻段另可指定T/RH。入口由上一段連動。H1／H2可分別選電熱、回收熱水、兩者並用或停用，熱水可共同或分段設定。

循環水洗濕膜、電極式蒸汽及電熱式蒸汽加濕是不同設備。濕膜有蒸發冷卻效應，不能把所有加濕都當成等溫；電極蒸汽需核原廠導電率範圍，不能直接假設DI／UPW可用。

## 案例18：58,000 CMH、冬季預熱不足的方案

| 設計條件 | 數值 |
| --- | --- |
| 風量及基準 | 58,000 CMH，送風狀態 |
| 夏季外氣 | 35°C／70%RH |
| 冬季外氣 | 5°C／40%RH |
| 送風目標 | 22°C／55%RH |
| H1／H2熱源 | 電熱；已配置400／200 kW |
| 水洗 | 循環水洗濕膜，AMC需求持續水洗、有效度0.85 |
| C1供回水／候選容量 | 14／19°C、250 US RT |
| C2供回水／候選容量 | 7／12°C、160 US RT |
| 本例其他設定 | 各段自動需求、風機入氣流熱0、容量餘裕0%、回收熱水未上線 |

| 需求結果 | 夏季 | 冬季 |
| --- | --- | --- |
| 乾空氣質量流率 | 18.9921 kg/s | 同左 |
| H1預熱入空氣需求 | 0 kW | 573.141 kW |
| C1空氣側冷卻需求 | 719.429 kW | 0 kW |
| 濕膜蒸發量 | 17.011 kg/h | 472.385 kg/h |
| C2空氣側冷卻需求 | 501.289 kW | 0 kW |
| H2再熱入空氣需求 | 183.509 kW | 86.499 kW |
| H1已配置容量是否滿足 | 是 | **否：400 kW不足** |

本例水洗額定619.4 kg/h與濕膜有效度均為範例條件，非任何廠商產品的性能證明。空氣側與水側冷量因凝結水能量處理可能略有差異，選型比較應讀水側結果。

公式：`ṁ乾=送風CMH/3600/送風比容`；`空氣段需求kW=ṁ乾×Δh`；`水分量kg/h=ṁ乾×Δw×3600`。蒸發、蒸汽、凝結水分開收支；有風機熱時須納入再熱與總能量平衡。

**圖上的需求點是為達目標而反算的狀態，不代表400 kW預熱器實際能做到。** 本例冬季H1及H2共需約659.64 kW，不能把「總配置600 kW」當成已合格，也不能把H2餘額直接搬到H1預熱位置。若改風量或加入30／24°C回收熱水，應重新計算每一段可達溫度、熱水盤管同工況能力及容量檢核。

盤管ADP／旁通、同工況選型、風機與N−1性能、濕膜循環泵流量／揚程及控制連鎖仍需供應商資料。未提供資料時保留待補，沒有把空白當成設備已通過。本案例原於 V5.5.4 驗算，V5.5.5 保留相同工程模型；未在本表列出的條件沿用該案例原始預設，完整有效值與檢核結果見[情境18原始結果](../examples/calculation-results-windows.json)。
