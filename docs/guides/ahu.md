## 現行原始碼：MAU、DCC、FFU 的分工與圖表

本節是目前來源的工程／介面修訂，與下方保留的已發布版本驗算案例分開；下載區原 EXE／DMG 的版本及測試紀錄不因來源修改而改寫。

完整主案 MAU 模式新增明確的氣流路徑與 ACH 基準。舊案預設保留「獨立FFU循環（MAU直接入室）」：FFU 與沿用循環風量的 DCC 均採原循環量，不額外加 OA。若實際是「MAU入靜壓箱經FFU送風」，再選 ACH 代表基本回風循環或已含 OA 的 FFU 總送風；兩種基準分別是 `FFU=循環＋OA` 或 `DCC=FFU−OA`。回風小於零會列未達，不截為零來掩蓋問題。完整對照見[工作台指南](workbench.md#source-revision)。

主案先由排氣、漏氣、人員與除濕需求確定最終 OA，再計 FFU 台數、風機入室熱與 DCC 顯熱。DCC 的空氣側能力檢核使用與報告同一風量，並採夏冬較大需求；既有獨立 DCC 風量選項仍有效。原門縫孔口法在 0 Pa 不產生壓差外洩，新增基準 ACH 法只是替代初估。不要把基準 15 Pa／1 ACH 或 85% 安裝比例當作所有潔淨室的法規值。

分段單機仍是以外氣入口、逐段設備與最終送風目標計算的空調箱，並不等同於完整 FFU／DCC 回風迴路。主案帶入的室內基準 CMH 與單機送風狀態 CMH 要按同一乾空氣質量流率換算，不能把不同狀態的體積數字直接相加。MAU＋DCC＋FFU 的主案欄位和報表會分列乾盤管及 FFU；不要用 FCU 台數或 FCU 顯熱代表這兩種設備。

系統圖改為可隨寬度調整的彩色氣流圖：OA 綠、冷卻盤管青、加熱／再熱橘、送風與 FFU 藍、排氣琥珀；狀態卡顯示溫度、相對濕度與焓。KPI 與結構化明細提供需求及檢核結果。這些狀態仍是目標／計算需求；設備容量不足時不能把圖上的目標點當成實際可達出風。


**Seasonal AHU stage requirements and installed-capacity comparison.** 「完整工程工作台 → 空調箱管理 → 開啟選取單機」可設定冬夏工況，各段採自動需求、旁通或指定出口乾球；冷卻段另可指定T/RH。入口由上一段連動。H1／H2可分別選電熱、回收熱水、兩者並用或停用，熱水可共同或分段設定。

循環水洗濕膜、電極式蒸汽及電熱式蒸汽加濕是不同設備。濕膜有蒸發冷卻效應，不能把所有加濕都當成等溫；電極蒸汽需核原廠導電率範圍，不能直接假設DI／UPW可用。

停用欄位只保留草稿，不參與狀態點、容量、耗電、用水或報告。H1／H2 選回收熱水或停用時，不使用其電熱效率與額定電熱；熱回收未上線時，不列採用熱水工況。只有選用水洗設備才列循環水量、泵揚程與水洗補水；只選蒸汽時列蒸汽需求。名目電力統一為已選電熱器＋已選蒸汽發生器＋EC 風機額定，循環泵及附屬設備另列／另確認，不能當成同時運轉實耗電。

主案空調頁的「夏季一段盤管模式」只作用於夏季，冬季固定旁通；若要逐段設定冬季預熱、預冷、再冷與再熱，請在本單機分季控制內設定。

先看[新手教學第 8 節](workbench.md#ahu)，用小型 MAU 練習入口／出口、夏冬模式與預覽回傳；下方大風量案例適合已有操作基礎後閱讀。

## 案例18：58,000 CMH、冬季預熱不足的方案

| 設計條件 | 數值 |
| --- | --- |
| 風量及基準 | 58,000 CMH，送風狀態 |
| 夏季外氣 | 35°C／70%RH |
| 冬季外氣 | 5°C／40%RH |
| 送風目標 | 22°C／55%RH |
| H1／H2熱源 | 電熱；已配置400／200 kW |
| 水洗 | 循環水洗濕膜，AMC需求持續水洗、有效度0.85 |
| C1供回水／候選容量 | 14／19°C、250 US RT |
| C2供回水／候選容量 | 7／12°C、160 US RT |
| 本例其他設定 | 各段自動需求、風機入氣流熱0、容量餘裕0%、回收熱水未上線 |

| 需求結果 | 夏季 | 冬季 |
| --- | --- | --- |
| 乾空氣質量流率 | 18.9921 kg/s | 同左 |
| H1預熱入空氣需求 | 0 kW | 573.141 kW |
| C1空氣側冷卻需求 | 719.429 kW | 0 kW |
| 濕膜蒸發量 | 17.011 kg/h | 472.385 kg/h |
| C2空氣側冷卻需求 | 501.289 kW | 0 kW |
| H2再熱入空氣需求 | 183.509 kW | 86.499 kW |
| H1已配置容量是否滿足 | 是 | **否：400 kW不足** |

本例水洗額定619.4 kg/h與濕膜有效度均為範例條件，非任何廠商產品的性能證明。空氣側與水側冷量因凝結水能量處理可能略有差異，選型比較應讀水側結果。

公式：`ṁ乾=送風CMH/3600/送風比容`；`空氣段需求kW=ṁ乾×Δh`；`水分量kg/h=ṁ乾×Δw×3600`。蒸發、蒸汽、凝結水分開收支；有風機熱時須納入再熱與總能量平衡。

**圖上的需求點是為達目標而反算的狀態，不代表400 kW預熱器實際能做到。** 本例冬季H1及H2共需約659.64 kW，不能把「總配置600 kW」當成已合格，也不能把H2餘額直接搬到H1預熱位置。若改風量或加入30／24°C回收熱水，應重新計算每一段可達溫度、熱水盤管同工況能力及容量檢核。

盤管ADP／旁通、同工況選型、風機與N−1性能、濕膜循環泵流量／揚程及控制連鎖仍需供應商資料。未提供資料時保留待補，沒有把空白當成設備已通過。本案例原於 V5.5.4 驗算，V5.6.0 沿用相同工程模型；未在本表列出的條件沿用該案例原始預設，完整有效值與檢核結果見[情境18原始結果](../examples/calculation-results-windows.json)。
