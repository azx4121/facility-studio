<a id="source-revision"></a>
## 現行原始碼：熱負荷 → 冰水 → 泵浦

本節功能已包含於 Windows win.7／macOS mac.6；後續僅套用 Windows 的稽核修正見下方說明。

「熱負荷初估」分列照明、圍護、人員顯熱／潛熱、設備入室熱與 FFU 風機熱。圍護 20 W/m²、FFU 0.18 kW/台、外氣焓差 50 kJ/kg 是可改的初估假設。選外氣焓差終點時要維持控制體一致：

| 外氣焓差基準 | 冰機總冷量的初估邏輯 |
| --- | --- |
| 外氣至室內基準 | 室內顯熱＋人員潛熱＋MAU 外氣全熱；中性供風近似下 DCC 負荷取室內顯熱 |
| 外氣至實際露點送風 | DCC 顯熱＋MAU 全熱；不再加一次已由低露點送風處理的人員潛熱 |

實際露點模式若另填「MAU入室顯熱供冷抵扣」，DCC 需求會減去此值；還必須明填「室內減MAU送風溫差」。抵扣不得超過 `1.2×OA/3600×1.006×溫差` 的保守空氣側上限。未填抵扣只作未抵扣冷量上界；零 OA 卻有人員潛熱會拒絕計算。快算不解完整含濕比、再熱及設備可達性，正式乾盤管需求請用完整主案熱濕平衡覆核。

完成熱負荷後，到「冷熱水快算」按「帶入上游結果」帶入總 kW，再確認實際水側 ΔT。進階欄位可填最不利路徑長、ΣK、設備與末端壓降；粗糙度預設 0.045 mm，內徑與粗糙度都轉為 m 後計算無因次 ε/D。並聯管按各支流量計算。設備壓降為零表示未納入，不代表設備沒有阻力。

在「冰水泵浦」帶入水量及已計路徑損失揚程；額外末端損失只填前一步尚未包含部分。計算採 `H=(路徑損失＋額外末端損失)×(1＋裕度%/100)＋開式靜揚程`；閉式系統的靜揚程填 0，不加樓高。

| 功率名稱 | 清水快算定義 | 用途 |
| --- | --- | --- |
| 水功率 | Q(m³/h)×H(m)×9.81/3600 | 流體得到的功率 |
| 泵浦軸功率 | 水功率/泵效率 | 馬達機械輸出需求 |
| 馬達輸入電功率 | 軸功率/馬達效率 | 帶入配電用電 |
| 建議馬達銘牌 | 軸功率×1.15，再向上選標準級距 | 額定機械輸出 kW，不是輸入電功率 |

超過 75 kW 參考馬達表時顯示另選，不硬套最大規格。揚程仍需泵曲線、NPSH、末端設備及實際迴路資料；未提供完整設備壓降時，選泵僅是管路小計。總覽中的冰機冷量也不能直接作為冰機輸入電功率，見[配電帶入範圍](electrical.md#source-revision)。


**Cooling-water / chilled-water flow and heat calculator.** 開啟左側「冷熱水快算」，選「已知水量」或「已知熱量」。基本採清水密度1,000 kg/m³、比熱4.1868 kJ/(kg·K)、水速上限1.5 m/s；流量可用LPM、US GPM或m³/h。

V5.6自動表擴充至30吋，先選符合水速的單管，仍不足才並聯。新增14–24吋採碳鋼STD壁厚9.5mm參考內徑，實供壁厚不同請在工作台填實際內徑。例：7,000 LPM／1 m/s → 單支16吋、ID387.4mm；30,000 LPM／2 m/s → 單支24吋、ID590.6mm。[尺寸來源與驗證](../2026-10-12-v5.6-expansion.md)

公式：`Q[kW]=LPM/60000×ρ×cp×ΔT[K]`。US RT採3.51685284 kW/RT；ΔT是供回水溫差，不是其中一個水溫。乙二醇或其他液體應改用適用物性；快算清水值不能直接套用。

<a id="case-10"></a>
## 案例10：PCW 100 LPM、ΔT 5 K

選「已知水量」填100 LPM及5 K。
`100/60000×1000×4.1868×5=34.89 kW≈9.921 US RT`。
按1.5 m/s上限定寸，候選40A（1-1/2英吋）、參考內徑40.9 mm，水速1.269 m/s。

<a id="case-11"></a>
## 案例11：CHW 100 kW、ΔT 5 K

選「已知熱量」填100 kW及5 K。
`LPM=100×60000/(1000×4.1868×5)=286.615 LPM`。
候選65A（2-1/2英吋）、參考內徑67.9 mm、水速1.319 m/s。

候選僅符合指定水速；不代表整個水系統已合格。水泵揚程、換熱器／盤管壓降、完整供回水路徑、膨脹槽、靜壓及NPSH另核。

案例輸入：[10](../examples/10-water.json)、[11](../examples/11-water.json)。[來源反算記錄](../evidence/2026-10-18-audit-six/windows-use-cases.json)。



2026-10-16：26／28／30 吋 STD 參考內徑分別為 641.4／692.2／743.0 mm（外徑減兩倍 9.5 mm 壁厚）；依[供應商表格](https://www.snyi.com.tw/product-femco01.html)核對，仍需確認實供材質與壁厚。

## Windows win.7：ΣK 報告與泵浦單位

水管 TXT／HTML 列出計算實際採用的 ΣK；局部壓損仍為 `Δp=ΣK×ρ×v²/2`，不是把原本已正確的壓損再加一次。泵浦單位切換保留物理流量：100 LPM＝6 m³/h≈26.4172 US GPM。相同揚程與效率下，軸功率、輸入電力及建議馬達保持一致。這些修正始於 win.6，win.7 保留；mac.6 尚未套用。[修正與驗算](../2026-10-18-windows-audit-six.md)。
