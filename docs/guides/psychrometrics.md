本頁對應 **Facility Studio 5.7.3**。開啟左側「空氣狀態／線圖」，填 A 點乾球 °C／相對濕度 %RH；可勾「比較第二個空氣狀態」填 B 點，選「B點代表」室內或盤管出風／送風。有效結果會更新兩點與差值。進階「所在地大氣壓」用 kPa(abs)，預設 101.325，兩點共用同一壓力；不填表壓。

## 案例12：35°C、70%RH、101.325 kPa(abs)

| 空氣性質 | 結果 |
| --- | --- |
| 含濕比 | 25.159 g/kg乾空氣 |
| 焓 | 99.771 kJ/kg乾空氣 |
| 露點 | 28.701°C |
| 濕球 | 30.059°C |
| 比容 | 0.90827 m³/kg乾空氣 |

公式：`Pw=RH/100×Pws(T)`；`w=0.621945×Pw/(P−Pw)`；`h=1.006T+w(2501+1.86T)`。P與Pw必須使用相同單位，w在焓公式中用kg/kg乾空氣，不能直接代入g/kg。

<a id="case-13"></a>
## 案例13：25°C、50%RH、大氣壓80 kPa(abs)

進階大氣壓改80。含濕比12.568 g/kg乾空氣、焓57.167 kJ/kg乾空氣、露點13.864°C、濕球17.332°C、比容1.09139 m³/kg乾空氣。相同乾球／RH下，水蒸氣分壓相同；含濕比及比容會隨總壓變化，不能全採海平面數值。

RH=0%時不存在有限露點，軟體不以假數值代替。冬夏盤管容量還需要乾空氣質量流率及進出口狀態；單一空氣點不能推得空調總負荷。


案例輸入：[12](../examples/12-air.json)、[13](../examples/13-air.json)。反算另以Buck飽和水蒸氣壓關聯式核對含濕比／焓，容許0.3%近似差異，見[記錄](../evidence/2026-10-18-audit-six/windows-use-cases.json)。


## 完整線圖與快照

1. 先取得有效結果，按「放大空氣線圖」。完整圖包含乾球／含濕比格線、10–100% RH、等焓、等濕球與比容線，依目前壓力重繪。
2. 橫軸乾球 °C，右側含濕比 g/kg乾空氣；外側綠色刻度為焓 h，褐色 WB 為濕球，紫色 v 為比容。焓與濕球不是同一刻度。
3. 「放大 ＋」／「縮小 −」或滾輪縮放，拖曳平移；「適合視窗／重設」或雙擊回到全圖。「最大化」放大視窗，Esc 或「關閉」退出。
4. 放大視窗是**開啟當下的快照**，不是即時畫面。改 A／B 或大氣壓後，先讓主頁重算有效，關閉舊圖再開啟。

A／B 連線只比較端點，不保證實際設備過程。盤管冷熱量另需風量、乾空氣質量流率與合適狀態基準；不能從一條線宣稱選型已通過。
