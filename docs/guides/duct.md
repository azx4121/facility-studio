# 風管尺寸計算器：風量、方管、圓管與靜壓預算

[English](duct.en.md) · [回到工具指南](README.md) · [下載](../../README.md#下載)

**Rectangular / round duct sizing and static-pressure budget.** 「風管尺寸」預設只需風量 CMH／CFM／L/s，先算方管／圓管尺寸；不要求填靜壓。需要壓力核對時，勾選「我已知路徑」，再填可用靜壓、長度、管件與設備壓降。進階可調風速、寬高比與物性。基本風速上限8 m/s、方管寬高比上限2；這是初估參考，並非所有送風、酸鹼排氣或噪音條件的適用值。

<a id="case-03"></a>
## 案例03：3,000 CMH、200 Pa

風速上限8 m/s、寬高比上限2，未提供路徑。

| 結果 | 方管 | 圓管 |
| --- | --- | --- |
| 參考尺寸 | 350 × 300 mm | Ø406.4 mm（16英吋） |
| 實際風速 | 7.937 m/s | 6.424 m/s |
| 未採用的靜壓草稿 | 200 Pa（本模式不檢查） | 同左 |
| 壓力是否足夠 | 未核路徑 | 未核路徑 |

公式：`A=CMH/3600/v`，`D圓=√(4A/π)`。離散尺寸會使實際速度低於上限。**靜壓不能單獨決定尺寸；沒有路徑就不判定200 Pa是否足夠。**

<a id="case-04"></a>
## 案例04：2,000 CFM、已知20 m路徑

選CFM，輸入2,000；可用靜壓300 Pa。勾選「我已知路徑」，填直管20 m、管件ΣK=4、設備及末端100 Pa、風速上限8 m/s。其餘基本值不變。

| 結果 | 方管 | 圓管 |
| --- | --- | --- |
| 風量 | 3,398.022 CMH | 同左 |
| 尺寸 | 400 × 300 mm | Ø406.4 mm（16英吋） |
| 實速 | 7.866 m/s | 7.277 m/s |
| 本路徑總阻力 | 286.912 Pa | 254.095 Pa |
| 靜壓餘裕 | 13.088 Pa | 45.905 Pa |

公式：`Δp=f(L/Dh)ρv²/2+ΣKρv²/2+設備壓降`；方管速度用**真實矩形面積**計算，Dh是水力直徑，不能把Dh當成等面積圓管再算風速。本例採空氣密度1.2 kg/m³、黏度1.81×10⁻⁵ Pa·s、粗糙度0.09 mm。

這個快算路徑假設尺寸與流量沿線不變；完整多支路、各段尺寸、污染物處理、風機曲線與濾網終阻力另核。不得把設備端要求靜壓的最大值當成全管網 ESP。

案例輸入：[03](../examples/03-duct.json)、[04](../examples/04-duct.json)。[來源反算記錄](../evidence/2026-10-18-audit-six/windows-use-cases.json)。

## 目前來源修訂：等摩擦圓管換算

路徑檢查新增「Huebscher 等摩擦圓管」選項，舊案預設的實際矩形風速＋水力直徑法保留。令 a、b 為同單位的矩形邊長：`De = 1.30 × (a*b)^0.625 / (a+b)^0.25`。直管摩擦採等效圓管風速 `Ve = 4Q/(πDe²)`，不能將實際矩形風速配 De；彎頭等局部損失仍依實際構件風速壓計算。粗糙度輸入為 mm，與直徑一併轉為 m 後求無因次 ε/D。

此修訂已包含於 Windows win.4／Mac mac.6；原案例與歷史下載版紀錄保留。見[整合覆核與原生驗收](../2026-10-16-gemini-integration-review.md)。
