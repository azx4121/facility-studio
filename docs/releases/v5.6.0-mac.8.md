# Facility Studio V5.6.0 · mac.8

macOS 版與 Windows win.10 出貨同一份計算、品質閘門與報告程式碼（內容見 [win.9](https://github.com/azx4121/facility-studio/blob/main/docs/releases/v5.6.0-win.9.md)、[win.10](https://github.com/azx4121/facility-studio/blob/main/docs/releases/v5.6.0-win.10.md)）。

mac.8 的畫面與 mac.7 相同：macOS 本來就是 1 pt＝1 px 與 ttk 導覽，Windows win.10 改成與它一致。本版改動只有版本標示、教學參考報告，以及把「字級換算」寫成兩平台共用的規則（macOS 上結果不變）。新增 `ui_scaling_checks` 與 macOS 版 `text_clipping_checks`（90 項）。

下載 **Facility_Studio_V5_6_0_macOS_mac8.dmg**；教學與設備範本已內建，執行不需另裝 Python。打開 DMG，將 Facility Studio 拖至「應用程式」後啟動。

發布要求 Apple Silicon 與 Intel macOS 15 原生驗收（建置、簽章、啟動、自我測試）通過；這次分支驗收的 Intel 自我測試第一次因一項 UI 互動效能預算超過 0.04 秒（5.04 秒對 5 秒）失敗，其餘檢查通過，重跑通過。實體 Mac、其他 macOS 版本與公司管理政策仍須現場確認。只有 ad-hoc 完整性簽章，沒有 Developer ID 或 Apple 公證；首次開啟可能需要「系統設定 → 隱私權與安全性 → 仍要打開」。本版驗證的是計算實作與選型合理性，不是規範符合性。mac.7 與所有歷史 Release 保留。

English: mac.8 ships the same calculation, quality-gate and report code as Windows win.10. The macOS look is unchanged from mac.7 (macOS already drew 1 pt as 1 px with ttk navigation; Windows win.10 now matches it). Changes: revision labels, tutorial reference reports, and the text-size rule written as one shared rule (same result on macOS); new `ui_scaling_checks` and a macOS `text_clipping_checks` (90 checks). Publication requires native Apple Silicon and Intel macOS 15 acceptance; on the branch run the Intel self-test failed once on a UI timing budget (5.04 s against 5 s) with all other checks passing and passed on rerun. Physical Macs, other macOS versions and managed-device policies need on-site checks. Ad-hoc signature only. Not proof of code compliance. mac.7 and historical releases are preserved.
