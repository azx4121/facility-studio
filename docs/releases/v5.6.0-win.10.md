# Facility Studio V5.6.0 · win.10

本版只改畫面：Windows 版的視窗改成與 macOS 版一致。計算、品質閘門與報告內容與 [win.9](https://github.com/azx4121/facility-studio/blob/main/docs/releases/v5.6.0-win.9.md) 相同。

| 項目 | 本版行為 |
| --- | --- |
| 文字大小 | 字型以「點」設定，Tk 在 Windows 把 1 pt 畫成 1.33 px，在 macOS 畫成 1 px，所以同一個視窗在 Windows 的文字比 macOS 大約三分之一。win.10 起 Windows 採用與 macOS 相同的換算（100 % 顯示縮放下 1 pt＝1 px）；顯示縮放 125 %、150 % 時文字仍依比例放大。**所以 win.10 的文字比 win.9 小。** |
| 完整工作台左側導覽 | Windows 原本是自動換行的 tk 按鈕，macOS 是 ttk 樣式按鈕；現在兩個平台都用同一種 ttk 樣式（選取項目粗體），英文長標籤不再換行。 |
| 其他 | 版本標示 `5.6.0-win.10`；教學參考報告與安裝程式內容同步更新。 |

兩個平台仍出貨同一份 `facility_studio`（`tools/verify_platform_sync.py` 檢查），只有版本標示與內建教學不同。兩平台的字型與視窗外框由作業系統提供（Windows：Microsoft JhengHei UI／Consolas；macOS：PingFang TC／Menlo），所以不會逐像素相同。

發布前在分支與 main 上各跑一次 Windows Server 2022／2025 原生建置與驗收（斷網、隱藏外部 Python）。實體 Windows 10／11 在 125 %／150 % 縮放下的實際外觀尚未確認。尚無正式 Authenticode 簽章。本版驗證的是畫面尺寸規則與計算實作，不是 FEED、醫院感染控制、藥廠 GMP 或電氣法規的符合性證明。所有歷史 Release 保留。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，雙擊即可使用，內建 Python、教學及設備範本。

English: win.10 changes the look only. Calculations, quality gates and reports equal win.9. Tk draws 1 pt as 1.33 px on Windows but 1 px on macOS, so the same window showed about one third larger text on Windows. Windows now uses the macOS mapping (1 pt = 1 px at 100 % display scaling; 125 % / 150 % screens still scale up), so **win.10 text is smaller than win.9**. The full-workbench side navigation is now the same ttk style on both platforms (selected item in bold). Both platforms still ship the same `facility_studio` package. Fonts and window frames come from each system, so the two are not pixel-identical. Native Windows Server 2022/2025 build and acceptance run before publication; appearance on physical Windows 10/11 at 125 % / 150 % scaling is not yet confirmed. No Authenticode signature. This is not proof of FEED, hospital infection-control, GMP or electrical-code compliance. Historical releases are preserved.
