# Facility Studio V5.6.0 · win.8

修正報告可追溯性與串接輸入驗證，保留 win.7 的來源復原、F01–F06 及照明 F07 修正。

| 項目 | 本版行為 |
| --- | --- |
| R01 管長與輸入 | 串接服務拒絕未知工具／欄位與重複 water／pipes，避免拼錯欄位後默默採預設值。50 m 測試直接核對採用管長、壓差及連動泵浦水頭。 |
| R02 電流說明 | 一般負載顯示實際 1.0 倍，連續／馬達顯示 1.25 倍，並列運轉電流與設計電流的算式。HP／PS 按馬達負載處理。 |
| R03 設計依據 | 簡易 HTML 與串接 TXT／HTML 列出實際採用條件；串接彙總分列 FFU、照明、CHWP、MAU、製程及冰機輸入電力與 COP／明填電力依據。工作台列 RCU／FCU／DCC 單台額定及台數比較。 |
| R04 單位 | 固定單位與欄位一併保存，TXT／HTML 補上 m、°C、K、W、mm 等；面積／體積依模式標示，無因次係數不誤加單位。 |
| R05 版本 | 報告標示產品版本、Windows 與 win.8 修訂，與封裝版本一致。 |

新增 405 項報告語意檢查與 28 項實際匯出／PV 操作，並放入封裝 EXE 驗收。只有計算結果而未附原始輸入的舊格式，報告明確提示缺少採用條件，不以預設值補造。

首頁與工作台新增「PV 真空」按鈕，直接展開「特氣與真空」並捲到 PV 欄位，避免預設空調範圍隱藏入口。開啟不修改專案數值；驗證 Torr／kPa／mbar 絕壓切換及相同抽氣量的計算一致性。PV 使用專用絕壓欄位，不混入正壓氣體選單。

本版亦加強驗收末尾的畫面檢查：清理測試用 TkAgg 畫布後，驗證最小化還原及工具切換後的表單映射與實際畫面像素。原生結果與圖片將記錄於本版檢測文件；功能斷言不替代實體 Windows 10／11 的 DPI 與企業環境驗收。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，雙擊即可使用，內建 Python、教學及設備範本。發布要求相同 EXE 在 Windows Server 2022／2025、獨立檔／ZIP 解壓／中文路徑均通過。Windows 10／11 x64 為支援目標；尚無正式 Authenticode 簽章。

只修正 Windows；mac.6 保留。Windows ledger v2 整案仍不能由 mac.6 開啟；舊版已錯存的 W／kVA 電力來源仍須由原始資料重新帶入。所有歷史 Release 保留。

English: win.8 rejects unknown pipeline fields instead of silently retaining defaults, corrects circuit-duty explanations, exports adopted inputs and equipment power sources, shows terminal unit ratings and governing counts, adds fixed input units and identifies Windows win.8 in reports. Adds 405 semantic checks and 28 actual export / PV checks to delivered-runtime acceptance. Direct PV vacuum buttons expose and scroll to vacuum fields even under the HVAC task scope; pressure conversion and flow equivalence are checked. Native capture now checks real form pixels after disposal of the test-only TkAgg canvas and a minimize/restore cycle. Publication requires both native Windows gates; the physical Windows 10/11 DPI review is separate. mac.6 and historical releases are preserved.
