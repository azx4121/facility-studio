# Facility Studio V5.6.0 · win.5

本版修正照明 F07：按「型錄 U／室指數檢核」不再將 m²、坪或體積改成隱藏的舊長寬，避免 75 m² 被改成 30 m²、燈數從 20 盞變成 8 盞。

- 保留目前面積模式、計算模式、燈具流明來源、U 與 M。
- 只有選擇長×寬且輸入實際尺寸時才啟用室指數 K；其他模式保留原計算並提示補齊幾何尺寸。
- 新增 2,500 項獨立公式核對與中英文實際按鈕回歸；同一操作也納入封裝 EXE 的原生驗收。
- 發布閘門仍要求 Windows Server 2022／2025 驗證相同交付檔通過，才公開資產。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，儲存後雙擊開啟；內建 Python、教學與設備範本。公開檔為 EXE 與 SHA256SUMS.txt。

這次只修正 Windows 照明 F07；先前稽核的 F01–F06 仍另案追蹤。macOS mac.6 及舊 Windows 版本保留。流明法仍屬平均照度初估，請依實際燈具配光與反射率選取 U。

English: Fixes F07, where the catalogue-U/room-index button replaced the current area with hidden dimensions and could reduce 20 luminaires to 8. The action now retains area, calculation mode and lumen source, and only enables K after length × width is selected. Independent formula checks and bilingual real-widget regressions are also included in native EXE acceptance. Publication requires both native Windows gates. Other audit findings F01–F06 and the macOS release are tracked separately.
