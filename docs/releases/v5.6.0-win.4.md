# Facility Studio V5.6.0｜Windows win.4

修正 MAU 外氣與 FFU 計算定義。正常運轉 OA、最大可用 OA、未來新增排氣／洩漏與安全餘裕分開輸入；最大能力不當成正常全量運轉。

24,900 m³、純回風 80 ACH、最大 OA 58,000 CMH 全經 FFU、單台 1,000 CMH：需求為 2,050 台。總送風 ACH 已含經 FFU 的外氣，不重複相加；排氣減少回風，外氣補足排氣與外流，不再次扣除 FFU 送風。

DCC 採回風端最小風量；MAU 盤管、水量與分段空調箱連動另核最大／未來外氣的夏冬工況，避免正常小風量造成設備選小。完整舊案自動移轉，原指定 OA 保留運轉用途，新容量待填。

只需下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，儲存後雙擊；免另外安裝 Python。SHA256SUMS.txt 可核對檔案身分。

發布由 Windows Server 2022／2025 的交付檔驗收共同控管。實際 EXE 執行共用 19 項 OA／FFU 檢查、100 組風量條件，以及原有 100 組不同工程條件各重算 20 次；同時測試新欄位、中英切換與模式互鎖。驗收包含外部 Python 隱藏、離線封鎖、Unicode 路徑與同一 EXE 的檔案 SHA256。

Windows 10／11 x64 為支援目標，實際環境與企業政策需個別確認；本版尚未取得正式發行者簽章。[首次安全提示說明](https://github.com/azx4121/facility-studio/blob/main/docs/signing.md)。
