Facility Studio V5.6.0 mac.5 調整 macOS 自動驗收的診斷方式，避免背景 traceback 執行緒在 GUI 操作或結束時引入額外的競爭與等待風險。一般使用時的計算、工程表、專案格式及操作功能不變。

自動驗收保留所有既有檢查，以及交付 App 內的 100 組不同物理情境、每組 20 次重算。25 秒診斷改由 Tk 主事件迴圈執行同步 traceback，結束前取消排程；外部程序逾時限制繼續保留。若事件迴圈停住，這個回呼無法執行，仍須靠外部程序判定逾時。

先前曾出現定時 traceback 後的 SIGSEGV，另一次加速診斷在完成 100 次語言切換後於清理階段逾時。原始 SIGSEGV 尚未取得可定位原因的原生 crash report，因此本修訂不能視為其根因已完全確認或已消除；兩次現象也未證實是同一原因。

候選版須通過 Apple Silicon 與 Intel Mac 對同一 ZIP／DMG 的原生驗收後才發布。測試分支只建立及驗證候選檔案，發布仍限 main。公開資產為 **Facility_Studio_V5_6_0_macOS_mac5.dmg** 與 **SHA256SUMS.txt**；既有 mac.4 下載保留。Apple Developer ID／公證尚未配置。

V5.6 的 24 吋水管參考、七個左側快算、50 種廠務氣體與自訂／混合氣、零需求草稿互鎖及中英雙語教學繼續保留。工程報告仍列出未達與待資料項目，軟體測試通過不代表每個工程案例符合全部設計條件。

English: Revision mac.5 changes automatic acceptance diagnostics from a background traceback watchdog to a synchronous callback on the Tk main event loop, cancelled before shutdown. All existing acceptance assertions, delivered-App 100-scenario stress checks and external process timeouts remain. Ordinary calculations, engineering tables and project formats are unchanged. The original SIGSEGV still lacks a native crash report sufficient to establish its cause; this revision does not claim that cause is proven or eliminated. Publication requires Apple Silicon and Intel verification of the same delivery files and remains restricted to main.
