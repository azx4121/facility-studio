Facility Studio V5.6：把設備功率、風量、水量與空間條件整理成可比較的廠務需求。繁體中文／English、離線教學及設備範本已內建。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，關閉舊程式後直接開啟；不需另裝 Python。完整舊專案可接續使用。

- 水管自動選型擴充至 **24 吋**，先選符合水速的單管，能力不足才並聯。新增管徑按 STD 參考壁厚計內徑。
- **七個快算直接放在左側**，冷熱水、空氣狀態與單位換算不再藏在下拉選單。
- 快算與工作台統一提供 **50 種廠務氣體＋自訂／混合氣**；新增氣體須填設計流速，快算支援 T/P/Z 換算。
- 修正重選同種製程氣體時清除已輸入流速；切換到不同新增氣體仍須填設計值。
- 保留小數點鍵盤修正、停用欄位互鎖及完整報告防護。

發布由 Windows 2022 建置及 Windows 2025 的離線原生驗收通過後執行；公開資產只有 EXE 與 SHA256SUMS.txt。[使用說明](https://github.com/azx4121/facility-studio#readme) · [尺寸來源、計算範圍與驗證](https://github.com/azx4121/facility-studio/blob/main/docs/2026-10-12-v5.6-expansion.md)。正式發行者簽章尚未配置。
