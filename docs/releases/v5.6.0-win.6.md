# Facility Studio V5.6.0 · win.6

本版修正 Windows 稽核 F01–F06，並保留 win.5 的照明 F07 修正。

| 項目 | 修正後行為 |
| --- | --- |
| F01 水管報告 | TXT／HTML 顯示計算實際採用的 ΣK。 |
| F02 電力摘要 | 斷路器 AT 與本次迴路的導線候選一致；主進線仍需另計。 |
| F03 來源帶入 | W、kVA、HP、A、kW 使用一致的有效功率換算；更新不重複累加，移除還原原值。 |
| F04 末端冷卻容量 | RCU／FCU 取夏冬較大盤管冷量並加設計餘裕；FCU 同時核對風量。 |
| F05 泵浦單位 | LPM、m³/h、US GPM 切換保留實際流量與耗電。 |
| F06 單位換算 | 無法表示的結果明確報錯；可表示的大數值及絕對零度正確處理。 |

舊版已錯存成 kW 的 W／kVA 帶入不會被猜改。若整案保留來源記錄，新版標示「舊版電力帶入需重建」，請先移除本盤已納入的電力來源，再以原始資料重新帶入；移除會在未手改時還原原始值與單位。若只剩主案 JSON、已無來源記錄，請自行比對原始 W／kVA 並重新輸入。

新增獨立數值、邊界與中英文真實介面回歸，也納入封裝 EXE 驗收。發布流程要求 Windows Server 2022／2025 使用相同 EXE，於獨立檔、ZIP 解壓及中文空格路徑全部通過，再公開 EXE 與 SHA256SUMS.txt。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe** 後雙擊開啟。內建 Python、教學與設備範本。Windows 10／11 x64 為支援目標，原生驗收環境為 Server 2022／2025；尚無正式 Authenticode 簽章。

macOS mac.6 保留，這批修正僅套用 Windows。舊 Release 與原始稽核證據保留。
