# Facility Studio V5.6.0 · mac.7

macOS 版與 Windows win.9 出貨同一份計算、品質閘門與報告程式碼，包含 F-1 荒謬風量防護、品質閘門狀態語意、冰水餘裕標示、PV 壓力提示與 U 值單位顯示（內容見 [win.9](v5.6.0-win.9.md)）。

下載 **Facility_Studio_V5_6_0_macOS_mac7.dmg**；教學與設備範本已內建，執行不需另裝 Python。打開 DMG，將 Facility Studio 拖至「應用程式」後啟動。

mac 專屬部分保留：Command 快捷鍵與 Cmd+Q、macOS 資料目錄、觸控板捲動、ttk 導覽按鈕、只在可見時繪製線圖並重用相同資料的線圖。

發布要求 Apple Silicon 與 Intel macOS 15 原生驗收（建置、簽章、啟動、自我測試）通過。Intel 的自我測試接近 300 秒上限，曾有一次逾時、重跑通過；實體 Mac、其他 macOS 版本與公司管理政策仍須現場確認。只有 ad-hoc 完整性簽章，沒有 Developer ID 或 Apple 公證；首次開啟可能需要「系統設定 → 隱私權與安全性 → 仍要打開」。

注意：空調箱預設值改為各段「旁通」、加濕「不加濕」、風量 5,000 CMH；舊範例請明列各段設定。本版驗證的是計算實作與選型合理性，不是規範符合性。mac.6 與所有歷史 Release 保留。

English: mac.7 ships the same calculation, quality-gate and report code as Windows win.9: the absurd-airflow guard, unified quality-gate statuses, chilled-water margin labels, PV pressure hints and U-value unit display. Mac-specific behaviour is kept (Command shortcuts, Cmd+Q, application-support data folder, trackpad scrolling, ttk navigation, visible-only plot drawing). Publication requires native Apple Silicon and Intel macOS 15 acceptance; the Intel self-test runs close to its 300-second limit (one timeout, passed on rerun). Physical Macs, other macOS versions and managed-device policies need on-site checks. Ad-hoc signature only, no Developer ID or notarization. Air-handler defaults are now bypass stages; state stage settings explicitly in older examples. Verification covers calculation and selection reasonableness, not code compliance. mac.6 and historical releases are preserved.
