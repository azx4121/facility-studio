# Facility Studio V5.6.0 · win.9

本版修正「供風溫差趨近零時，靜默輸出荒謬風量」的缺陷，統一品質閘門的狀態語意，並讓 Windows 與 macOS 出貨同一份計算與報告程式碼。

| 項目 | 本版行為 |
| --- | --- |
| F-1 荒謬風量 | 供風溫差趨近零時，原本可得約 7.4×10⁹ CMH 且只標「待補資料」。現在以三層防護處理：數值（容差錨定設計風量，不隨試算風量放大）、物理（冰水供水加 ADP 裕度仍不低於室內露點時，任何風量都無法除濕，直接標「未達條件」並寫出冰水須低於多少 °C）、工程（供風量相對基準風量的倍數超過上限即未達）。不以固定 ACH 上限遮蔽；Class 10 的 500 ACH 不被截斷，MAU 外氣量與 FFU 循環風量分開計。正常工況不變：560 個一般設計的結果與修正前逐項一致（浮點誤差 1e-9 內）。 |
| 品質閘門 | 狀態為「未達條件」「待補資料」「初估完成（待後續階段確認）」「初估檢核通過」。補齊使用者能填的資料後可到「初估完成」；只要有負荷，設備同工況選型一定是待後續，所以「初估檢核通過」只對無負荷的空房間出現。 |
| 冰水餘裕 | 報告分列「未加餘裕」與「含餘裕」並標明百分比，餘裕每迴路只加一次。 |
| PV 壓力 | 欄位提示與各單位檢查一致：1～760 Torr＝0.1333～101.325 kPa＝1.333～1013.25 mbar。 |
| U 值單位 | 欄位標示「依 U 值單位」，說明預設 kcal/(h·m²·K)（1 W/(m²·K)＝0.860 kcal/(h·m²·K)），報告列出外牆、樓板面積與 U 值及單位。 |
| 圖表標示 | 最小視窗時 A、B 兩個標示框在 Windows 原生字型下會重疊；空間不足時改為並排，仍不足則縮短下方標示。 |

兩個平台現在出貨同一份 `facility_studio`（`tools/verify_platform_sync.py` 檢查），只有版本標示與內建教學不同。Windows 導覽按鈕保留自動換行；macOS 的 ttk 按鈕不支援換行，沿用 ttk 樣式。

20 組代表性情境與 5 組非隨機邊界掃描（S-01～S-05）已納入測試；結果與限制見[本輪驗收](https://github.com/azx4121/facility-studio/blob/main/docs/2026-10-31-win9-mac7-acceptance.md)。這些是計算實作與選型合理性的驗證，**不是** FEED、醫院感染控制、藥廠 GMP 或電氣法規的符合性證明。

下載 **Facility_Studio_V5_6_0_Windows_Offline.exe**，雙擊即可使用，內建 Python、教學及設備範本。發布要求相同 EXE 在 Windows Server 2022／2025、獨立檔／ZIP 解壓／中文空格路徑均通過；實體 Windows 10／11 的 DPI 與企業環境另行確認。尚無正式 Authenticode 簽章。

注意：空調箱的預設值改為各段「旁通」、加濕「不加濕」、風量 5,000 CMH、送風 16 °C／90 %RH。舊範例若沒有明列各段設定，冬季加熱量會是 0 kW；請在專案中明列設定。所有歷史 Release 保留。

English: win.9 fixes the defect where a supply temperature difference near zero silently produced an absurd airflow (about 7.4×10⁹ CMH, shown only as "data pending"). Three guards (numerical, physical, engineering) refuse such designs as "Conditions not met" with the cause and the chilled-water limit, without a fixed ACH cap; ordinary designs are unchanged (560 recorded cases identical within 1e-9). Quality-gate statuses are unified, chilled-water margins are labelled before/after, PV pressure hints match per-unit ranges, the U-value unit is shown with the field, help and report, and overlapping A/B chart captions at the smallest window are separated. Windows and macOS now ship the same product package. Verification is calculation and selection reasonableness only; it is not proof of FEED, hospital infection-control, GMP or electrical-code compliance. Air-handler defaults are now bypass stages with no humidifier, 5,000 CMH and a 16 °C / 90 %RH supply target; state stage settings explicitly in older examples. Publication requires both native Windows gates; physical Windows 10/11 review is separate. Historical releases are preserved.
