# 常見問題

[English](faq.en.md) · [下載](../README.md#下載) · [使用指南](guides/README.md)

## 需要安裝 Python 或保持連網嗎？

不需要。Windows EXE 與 macOS DMG 已包含執行環境，計算、專案保存與設備表匯入在本機完成。內建教學也可離線閱讀；GitHub 文件、下載與更新連結需要網路。

<a id="compatibility"></a>
## 我的電腦可以用嗎？第一次怎麼開啟？

| 平台 | 目前下載與使用方式 | 已完成的原生驗收 |
| --- | --- | --- |
| Windows | Windows 10／11、Intel／AMD x64 為支援目標。下載 EXE，雙擊開啟；第一次請等候內建環境展開。 | Windows Server 2022／2025 x64 |
| macOS | Apple Silicon／Intel Universal App，封裝目標 macOS 11+。打開 DMG，拖到「應用程式」後開啟；安裝完成可退出 DMG。 | Apple Silicon／Intel macOS 15 |

Windows ARM、32 位元 Windows，以及其他 Mac 系統版本與實機未納入這次驗收。企業管理政策也可能限制執行。[完整驗收與下載雜湊](2026-10-10-v5.5.8-native.md)

更新前先關閉舊程式，再替換 EXE／App；已另存的工程專案與復原資料保留。

<a id="security"></a>
## 為什麼出現不明發行者或開發者無法驗證？

Windows 版尚無正式 Authenticode 簽章；Mac 版只有 ad-hoc 完整性簽章，尚無 Developer ID／Apple 公證。原生測試通過與 SHA256 一致，都不能替代正式發行者認證。

請先核對本倉庫的下載來源與 SHA256，再依[系統安全提示說明](signing.md)及公司政策處理。若防毒列出具體威脅、Mac 顯示已損毀，或程式沒有視窗，請保留完整提示並回報。

<a id="first-project"></a>
## 第一次要把所有系統都填完嗎？

可先用一個獨立工具處理手上的問題，例如電力配線、風管或冷熱水。

完整專案可從「新手教學」的第一案開始，完成[前六步](guides/workbench.md)就能輸出練習報告。「開啟練習新案」直接載入第二案：含分段空調箱的全外氣 MAU 範例。練習檔使用合成資料，之後再換成自己的現場條件。

<a id="results"></a>
## 「計算完成」「待補資料」「待重算」有什麼差別？

| 狀態 | 代表什麼 | 下一步 |
| --- | --- | --- |
| 計算完成 | 目前輸入可完成數值計算 | 仍須看容量檢核、採用條件與待補事項 |
| 待補資料 | 原廠性能、設備阻力或現場條件尚未確認 | 補入真實資料並覆核 |
| 未達條件 | 某項已知容量或工況未達要求 | 讀取原因、修改配置並重算 |
| 待重算 | 修改輸入後保留的上次有效結果 | 重算成功後才能匯出或回傳目前結果 |

灰色停用欄位會保留草稿，重新啟用時恢復並驗證；停用草稿不參與該模式的計算。基本模式收起的進階欄位則可能仍採用已保存的設定，請查看畫面的採用條件。

這些狀態不等於正式設計認證。短路／保護協調、完整管網、設備性能選型與 BIM 出圖需另行完成。

<a id="saving"></a>
## 專案、草稿和報告要怎麼保存？

- **儲存整案 JSON：**保存主案、空調箱、方案及需求來源，可重新開啟接續工作。「另存新檔」換檔名；「複製為新方案」建立新案件身分。
- **單機空調箱 JSON：**用「另存單機」保存。V5.5.8 遇到無效輸入時，可確認保存原始草稿；重新開啟後仍需修正才能計算／匯出。獨立單機沒有背景自動保存，離開前請手動保存。
- **TXT／HTML 報告：**供閱讀、列印或分享。HTML 可由瀏覽器列印成 PDF；報告不能當作整案重新開啟。

<a id="equipment"></a>
## 設備 Excel／CSV 怎麼開始？

在「設備表匯入」先匯出範本，填入實際設備，再匯入分析。要納入的設備請將「啟用(1/0)」設為 1；範本示例預設為 0。

支援範本格式的 `.xlsx` 與 `.csv`，不是任意 Excel 表格。舊 `.xls` 與巨集工作簿不接受；輸入公式請先貼上值。分析後可匯出結果，帶入主案前會先預覽與確認。[欄位與分組說明](guides/equipment.md)

<a id="support"></a>
## 開啟失敗或算出不同結果，怎麼回報？

到 [GitHub Issues](https://github.com/azx4121/facility-studio/issues)，提供版本、作業系統／CPU、操作步驟、完整輸入與單位、預期與實際結果，以及錯誤畫面。工程問題可加上自己的反算方式。

啟動失敗可一併提供記錄：

- Windows：`%LOCALAPPDATA%\Facility_Studio_V5_5\Logs`
- macOS 啟動記錄：`~/Library/Logs/Facility_Studio_V5_5/`；介面錯誤：`~/Library/Application Support/Facility_Studio_V5_5/error.log`

請使用測試資料並移除業主或現場機密。原生測試和歷史證據可從[文件中心](README.md)查閱。
